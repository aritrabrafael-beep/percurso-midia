# percurso-midia

Hospedagem das imagens da fábrica de conteúdo da Percurso.AI.

A API do Instagram não aceita upload de arquivo: ela busca a imagem numa URL pública.
Este repositório existe só para isso. O conteúdo é enviado por
`scripts/publicar-midia.ps1` da pasta `percurso-fabrica`, e a Vercel publica a cada push.

Não coloque nada sensível aqui: tudo neste repositório fica acessível publicamente.
